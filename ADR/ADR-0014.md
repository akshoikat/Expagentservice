ADR-0014
Container Separation

Decision

Platform will be deployed as three primary runtime containers:

Web
API
Worker

Business logic থাকবে packages/core-এ।

Provider integration থাকবে providers/-এ।

Infrastructure replace করা যাবে business logic পরিবর্তন না করেই।

এখানে আমি একটি গুরুত্বপূর্ণ proposal দিতে চাই

এখন পর্যন্ত আমরা Worker-কে একটাই container ধরেছি।

কিন্তু Worker-এর ভিতরে আমি Job Domain আলাদা করতে চাই।

যেমন:

apps/worker

├── ai/
├── communication/
├── media/
├── workflow/
├── knowledge/
├── maintenance/
└── scheduler/

এগুলো আলাদা process নয়।

একই Worker application-এর logical module।

উদাহরণ:

ai/ → LLM execution, summarization
communication/ → Retry outgoing message, webhook recovery
media/ → Image, audio, document processing
knowledge/ → Embedding generation, indexing
workflow/ → Delayed execution, automation
maintenance/ → Cleanup, archive, retention
scheduler/ → Cron-driven jobs

এর সুবিধা হলো V1-এ একটি Worker থাকবে, কিন্তু V2/V3-এ load বাড়লে আমরা সহজেই worker-ai, worker-media, worker-workflow আলাদা deploy করতে পারব। Code restructure করতে হবে না, শুধু deployment topology পরিবর্তন হবে।
