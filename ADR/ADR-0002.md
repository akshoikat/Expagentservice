🔒 ADR-0002 (Proposed)

Title: AI as a Core Runtime

Decision: AI will be implemented as a platform runtime, not as a feature of any individual business module.

Reason:

Consistent memory, prompt management, tool calling, and model routing across all domains.
Reusable agent infrastructure for every future product.
Easier testing and provider replacement.
Reduced duplication of AI-related code.


আমরা AI-কে আর আলাদা feature হিসেবে দেখব না।

AI হবে platform-এর Runtime।
