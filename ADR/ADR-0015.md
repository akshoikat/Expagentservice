ADR-0015 — Workspace-Centric Domain Model

Decision

The entire platform is organized around the Workspace as the root business boundary.

Every business entity belongs to exactly one Workspace unless explicitly defined as a global platform entity.

Benefits

Natural multi-tenancy.
Clear ownership.
Easier authorization.
Simpler data isolation.
Future enterprise support.
একটি গুরুত্বপূর্ণ architectural insight

এখন পর্যন্ত আমরা ধীরে ধীরে একটি pattern তৈরি করেছি:

Workspace → Ownership
Blueprint → Business Definition
Agent Instance → Runtime
Conversation → Execution Context
Workflow → Automation Logic
Knowledge Base → Domain Knowledge
Integration → External Connectivity

আমি লক্ষ্য করছি, এগুলো একসাথে মিলে একটি খুব পরিষ্কার mental model তৈরি করছে। এর মানে হলো নতুন developer project-এ যোগ দিলেও entity-গুলোর ভূমিকা সহজে বুঝতে পারবে।
