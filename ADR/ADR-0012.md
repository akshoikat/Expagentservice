🔒 ADR-0012 — Blueprint-Based Agent Architecture

Decision

The platform will use a single generic Agent Runtime.

Business-specific AI agents will be represented as Blueprints, not as separate runtime implementations.

A Blueprint is a declarative configuration that defines:

Persona
Instructions
Knowledge Sources
Memory Strategy
Tool Set
Workflow Rules
Safety Policies
Channel Permissions
Model Configuration

The Agent Runtime executes Blueprints without containing business-specific logic.
