Logical Modularity First, Physical Modularity Later.

🔒 ADR-0007 — Logical Before Physical

Decision

V1 will organize the system into logical domains inside packages/core.

Separate packages will be created only when a domain has a proven need for independent versioning, build lifecycle, or ownership.

Reason

Lower development overhead.
Simpler dependency graph.
Easier onboarding.
Clear upgrade path.

এটা পুরো platform-এর backbone হবে।
